# CAIN: русский перевод

Модуль переводит интерфейс системы CAIN, листы, библиотеки, таблицы, архивы и вычисляемые подсказки CAT. Названия доступны для поиска на русском и английском. Собственные подписи имеют приоритет над `ru-ru`.

## Использование

Включите `cain-ru` в мире с системой CAIN и выберите русский язык. `ru-ru` рекомендуется для интерфейса Foundry; Babele рекомендуется для библиотек. После обновления модуля полностью перезагрузите страницу мира.

Автоматическая замена касается исходных текстов системы и известных прежних переводов. Изменённые пользователем названия и описания сохраняются. Названия шрифтов, технические выражения CAT, UUID и некоторые имена организаций остаются в исходном виде.

## Проверка

Версия 0.1.1 проверена с CAIN 1.3.26 и Foundry 14.368: библиотеки через API Foundry, все типы листов, семь типов грехов, смена типа, поиск `weapon`/`оружие`, добавление предмета, сохранение пользовательского текста, перезагрузка, интерфейс ведущего и игрока, трекер охоты и окна инструментов.

При старте эта версия самой системы CAIN выдаёт ошибку обращения к `game.user.isGM` в `init`, когда пользователь ещё не загружен. Это отдельная ошибка системы; модуль перевода её не изменяет. Проверки перевода выполняются после загрузки мира.

## Инструменты

Инструменты рассчитаны на локальную установку Windows. Node.js нужен только для проверок, не для работы модуля в Foundry.

```powershell
npm install --prefix "$env:TEMP/cain-ru-testtools" jsdom acorn playwright
node tools/audit.mjs
node tools/check-library.mjs
node tools/test-runtime.mjs
node tools/check-ui.mjs
```

`audit.mjs` открывает только временные копии баз библиотек. `--snapshot` обновляет `data/originals.json`, необходимый для определения исходного текста и защиты пользовательских изменений. Исходные варианты переводов привязаны к коммиту `a6d01e7`.

`refine-library.mjs` выполняет повторяемые исправления переводов. Выражения CAT и ссылки обрабатываются отдельно от текста.

Для проверки настоящего Foundry используйте `prepare-foundry-test.mjs`: он создаёт отдельную установку в `%TEMP%/cain-ru-foundry-test`, копирует туда систему и модули и создаёт тестовых ведущего и игрока. При повторном запуске сбрасываются только пользователи и настройки этого тестового мира. Запускайте его при остановленном тестовом сервере. Ваши игровые миры не используются.

```powershell
node tools/prepare-foundry-test.mjs
node "C:/Program Files/Foundry Virtual Tabletop/resources/app/main.mjs" --dataPath="$env:TEMP/cain-ru-foundry-test" --port=30009 --world=cain-ru-test
```

В другом терминале выполните `node tools/test-foundry.mjs`. Тест использует установленный Microsoft Edge в фоновом режиме и создаёт данные только в тестовом мире. После проверки остановите тестовый сервер.
